Build Autonomous Coding Agents using Claude Code and AgentCore in AWS - Advanced Workshop
Developer attention — not compute — is the bottleneck in modern software engineering, yet coding agents running on developer laptops cannot be governed, cost-attributed, or run unattended at scale. In this half-day hands-on workshop, you will deploy coding agents on Amazon Bedrock AgentCore Runtime, orchestrate them from a single chat with each agent taking a specialized role in its own parallel microVM, grade results with deterministic tests (pytest, not a large language model), and layer on enterprise governance — identity attribution, per-user cost attribution, and fleet observability through Amazon CloudWatch. Each agent has a distinct job: one writes the implementation, another writes and runs test cases, and the orchestrator commits changes only after an automated review gate passes, then notifies a human for final code review and merge. You will leave with a working multi-agent system built on architecture patterns proven at scale .

Skip months of prototyping. Walk away with a working autonomous coding agent system built on AgentCore's three core capabilities — Runtime, Identity, and Gateway — that you can adapt to your own codebase and deploy from the command line.
